# AgriTrace 🌱

AgriTrace is a digital agricultural traceability and farm-to-buyer platform.

## Vision

AgriTrace connects farmers, buyers, and agricultural supply-chain participants through a transparent digital platform.

## Core Features

- Farmer and buyer accounts
- Farm and crop management
- Digital Crop Passport
- Crop traceability
- QR-based crop verification
- Pre-harvest marketplace
- Buyer reservations
- Orders and logistics
- Agricultural analytics
- Notifications

## Technology Stack

- Python
- Django
- Django REST Framework
- PostgreSQL
- HTML
- CSS
- JavaScript
- Git
